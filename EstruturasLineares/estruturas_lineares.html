// 01

Listas lineares — visão geral

analogia do dia a dia

Uma lista linear é como um vagão de trem: cada elemento tem um antecessor (exceto o primeiro) e um sucessor (exceto o último). A diferença entre os tipos de lista está em como a relação entre elementos é mantida na memória — contiguamente (vetor) ou através de ponteiros (nós).

Uma lista linear é uma sequência finita de elementos onde a ordem é determinada pela posição. As operações fundamentais de qualquer lista incluem:

  • Inserção — em qualquer posição
  • Remoção — por valor ou por posição
  • Busca — localizar um elemento
  • Percorrimento — visitar todos os elementos

Quatro formas de implementar listas lineares são estudadas: sequencial (estática), simplesmente encadeada, duplamente encadeada e circular.

// 02

Lista sequencial (estática)

Elementos armazenados em posições consecutivas de memória (vetor). O acesso é direto via índice — O(1). A desvantagem é o tamanho fixo (alocação estática).

TAD — Tipo Abstrato de Dados: Uma lista sequencial é definida por um vetor de tamanho máximo MAX e um inteiro n que controla quantos elementos estão efetivamente armazenados.

estrutura da lista sequencial — C
// Estruturas de dados: definições das listas
#define MAX 100

struct lista {
    int v[MAX];   // vetor com os elementos
    int n;         // número de elementos armazenados
};

typedef struct lista Lista;

Operações principais:

  • criar() — aloca a lista e inicializa n = 0
  • inserir(x, p) — insere o elemento x na posição p, deslocando os seguintes
  • remover(p) — remove o elemento na posição p, deslocando os seguintes
  • buscar(valor) — percorre o vetor procurando o valor
inserção na lista sequencial — C
int inserir(Lista *l, int x, int p) {
    if (l->n == MAX || p < 0 || p > l->n)
        return 0; // falha
    for (int i = l->n; i > p; i--)
        l->v[i] = l->v[i - 1];
    l->v[p] = x;
    l->n++;
    return 1; // sucesso
}
Lista: [10, 20, 30, 40, 50], n=5, MAX=10 Inserir 25 na posição 3: Desloca: 50→[4], 40→[3] Insere: [10, 20, 30, 25, 40, 50], n=6

Complexidade: Acesso O(1) | Inserção/remoção no início O(n) | Inserção/remoção no fim O(1) | Busca O(n)

O deslocamento de elementos é o custo principal. Inserir no início exige deslocar todos os n elementos. Inserir no fim é O(1) se houver espaço.

// 03

Lista simplesmente encadeada

Os elementos (nós) são alocados dinamicamente e ligados por ponteiros. Cada nó contém o dado e um ponteiro para o próximo nó. A lista é referenciada pelo ponteiro para o primeiro nó (inicio ou head).

Vantagem: Tamanho dinâmico — cresce e diminui conforme necessário. Inserção e remoção não exigem deslocamento de elementos.

Desvantagem: Acesso sequencial — para chegar ao nó na posição p, é preciso percorrer desde o início.

estrutura do nó — C
struct no {
    int           info;    // dado armazenado
    struct no *prox;     // ponteiro para o próximo nó
};

typedef struct no No;
inserção no início — C
/* Insere 'valor' no início da lista apontada por *l */
void inserirInicio(No **l, int valor) {
    No *novo = (No*) malloc(sizeof(No));
    novo->info = valor;
    novo->prox = *l;   // aponta para o antigo primeiro
    *l = novo;           // atualiza o início
}
Representação gráfica: [info | prox] → [info | prox] → [info | prox] → NULL ↑ inicio Inserir 5 no início: [5 | *] → [10 | *] → [20 | *] → [30 | NULL] ↑ inicio
remoção de um valor — C
int remover(No **l, int valor) {
    No *ant = NULL, *atu = *l;
    while (atu != NULL && atu->info != valor) {
        ant = atu;
        atu = atu->prox;
    }
    if (atu == NULL) return 0; // não encontrado
    if (ant == NULL)         // remoção do primeiro
        *l = atu->prox;
    else                      // remoção do meio/fim
        ant->prox = atu->prox;
    free(atu);
    return 1;
}

Complexidade: Acesso O(n) | Inserção/remoção no início O(1) | Inserção/remoção no fim O(n) | Busca O(n)

A grande vantagem da lista encadeada é a inserção e remoção no início serem O(1), sem necessidade de realocar ou deslocar dados.

// 04

Lista duplamente encadeada

Cada nó possui dois ponteiros: ant (para o nó anterior) e prox (para o próximo). Isso permite percorrer a lista nos dois sentidos e simplifica operações como remoção de um nó conhecido.

estrutura do nó — C
struct no {
    int           info;
    struct no *ant;  // ponteiro para o anterior
    struct no *prox;  // ponteiro para o próximo
};

typedef struct no No;
Representação: NULL ← [ant|info|prox] ↔ [ant|info|prox] ↔ [ant|info|prox] → NULL ↑ inicio
inserção no início — C
void inserirInicio(No **l, int valor) {
    No *novo = (No*) malloc(sizeof(No));
    novo->info = valor;
    novo->ant  = NULL;
    novo->prox = *l;
    if (*l != NULL)
        (*l)->ant = novo;
    *l = novo;
}
remoção de um valor — C
int remover(No **l, int valor) {
    No *atu = *l;
    while (atu != NULL && atu->info != valor)
        atu = atu->prox;
    if (atu == NULL) return 0;

    if (atu->ant != NULL)
        atu->ant->prox = atu->prox;
    else
        *l = atu->prox;    // remove o primeiro

    if (atu->prox != NULL)
        atu->prox->ant = atu->ant;

    free(atu);
    return 1;
}

Complexidade: Acesso O(n) | Inserção/remoção no início O(1) | Inserção/remoção no fim O(1) (com ponteiro para o fim) | Busca O(n)

A dupla ligação permite remover um nó sem precisar do nó anterior, e mantendo o ponteiro para o fim, a inserção no final também é O(1).

// 05

Lista circular

Em uma lista circular, o último nó aponta de volta para o primeiro, formando um ciclo. Pode ser implementada tanto sobre uma lista simplesmente encadeada quanto sobre uma duplamente encadeada.

Circular simplesmente encadeada: [info|prox] → [info|prox] → [info|prox] ←┐ └──────────────────────────────────────────┘ Circular duplamente encadeada: ┌──────────────────────────────────────────────┐ ↓ ant │ prox [ant|info|prox] ↔ [ant|info|prox] ↔ [ant|info|prox] ↑ prox │ ant └──────────────────────────────────────────────┘

Características:

  • Não há NULL nos ponteiros — o último prox aponta para o primeiro
  • A partir de qualquer nó, é possível percorrer a lista inteira
  • O percorrimento deve tomar cuidado para não entrar em loop infinito — é necessário um critério de parada
  • Útil para aplicações como escalonamento circular (round-robin), buffers circulares, jogos de turnos
percorrimento de lista circular — C
/* Percorre uma lista circular, parando quando
 * retorna ao nó inicial */
void percorrer(No *inicio) {
    if (inicio == NULL) return;
    No *atu = inicio;
    do {
        printf("%d ", atu->info);
        atu = atu->prox;
    } while (atu != inicio);
}

Resumo prático: Use lista sequencial quando o tamanho for conhecido e o acesso aleatório for frequente. Use lista encadeada quando houver muitas inserções/remoções e o tamanho for imprevisível. A dupla ligação é útil quando é necessário percorrer nos dois sentidos. A lista circular é ideal para aplicações que precisam de iteração contínua.

// 07

Exercícios de fixação

Quiz rápido

1. Qual a complexidade de inserir um elemento no início da lista sequencial?

✔ Correto! Inserir no início exige deslocar todos os n elementos uma posição à direita — O(n).
✘ Na lista sequencial, inserir no início exige deslocar todos os elementos — O(n).

2. Qual a principal vantagem de uma lista duplamente encadeada sobre uma simplesmente encadeada?

✔ Exato! O ponteiro ant permite navegação bidirecional e remoção direta de um nó.
✘ A dupla ligação permite percorrer nos dois sentidos e remover um nó conhecido sem precisar do nó anterior.

3. Em uma lista circular, como identificar que todos os nós foram percorridos?

✔ Correto! Na lista circular, o último nó aponta para o primeiro. O percorrimento usa um do-while comparando com o nó inicial.
✘ Em uma lista circular, não há NULL. O percorrimento é feito até retornar ao nó de partida.

4. Qual estrutura é mais adequada para uma aplicação com muitas inserções e remoções no início e tamanho imprevisível?

✔ Sim! A lista encadeada tem inserção/remoção no início O(1) e tamanho dinâmico — ideal para este cenário.
✘ Lista sequencial exige deslocamento O(n) no início e tem tamanho fixo. Lista encadeada é a melhor escolha.
