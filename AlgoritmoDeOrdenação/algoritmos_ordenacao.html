// 01

Ordenação — visão geral

analogia do dia a dia

Ordenar é como organizar cartas de baralho: você pode separar as cartas uma a uma (Selection), inseri-las na posição correta (Insertion), trocar adjacentes até tudo se acertar (Bubble), dividir o baralho ao meio recursivamente (Merge) ou escolher uma carta pivô e separar as menores das maiores (Quick).

Um conjunto ordenado reduz drasticamente o esforço computacional para encontrar um dado específico. Existem várias abordagens para ordenar, cada uma com vantagens e desvantagens em termos de complexidade de tempo e memória.

A aula aborda cinco métodos: Seleção, QuickSort, Inserção, Bolha e Intercalação (Merge Sort).

Estabilidade: um algoritmo de ordenação é estável se não altera a ordem relativa de elementos com chaves iguais.

In-place: um algoritmo é dito in-place quando utiliza apenas uma quantidade constante de memória adicional (além do próprio vetor).

// 02

Selection Sort — ordenação por seleção

O Selection Sort funciona encontrando o menor elemento do vetor e trocando-o com o elemento da primeira posição. Depois, encontra o segundo menor e troca com a segunda posição, e assim sucessivamente.

selection sort em C — smallerIndex e selectionSort
/* Encontra o índice do menor elemento a partir de ini */
int smallerIndex(int vet[], int tam, int ini) {
    int min = ini, j;
    for (j = ini + 1; j < tam; j++) {
        if (vet[min] > vet[j])
            min = j;
    }
    return min;
}

void selectionSort(int vet[], int tam) {
    int i, min, aux;
    for (i = 0; i < tam; i++) {
        min = smallerIndex(vet, tam, i);
        aux = vet[i];
        vet[i] = vet[min];
        vet[min] = aux;
    }
}
Exemplo: [64, 25, 12, 22, 11] Passo 1: menor = 11 → troca com 64 → [11, 25, 12, 22, 64] Passo 2: menor = 12 → troca com 25 → [11, 12, 25, 22, 64] Passo 3: menor = 22 → troca com 25 → [11, 12, 22, 25, 64] Passo 4: menor = 25 → troca com 25 → [11, 12, 22, 25, 64] Passo 5: menor = 64 → troca com 64 → [11, 12, 22, 25, 64]

Complexidade: Melhor caso O(n²) | Pior caso O(n²) | Estável: sim | In-place: sim

O Selection Sort sempre percorre todo o vetor restante para encontrar o menor elemento, independentemente de o vetor já estar ordenado. Por isso, seu melhor e pior caso são idênticos: O(n²).

// 03

Insertion Sort — ordenação por inserção

O Insertion Sort percorre o vetor da esquerda para a direita e, para cada elemento, desloca os maiores à sua direita para abrir espaço e insere o elemento em sua posição correta na parte já ordenada.

insertion sort em C
void insertionSort(int list[], int n) {
    int i, j, next;
    for (i = 1; i < n; i++) {
        next = list[i];
        for (j = i - 1; j >= 0 && next < list[j]; j--)
            list[j + 1] = list[j];
        list[j + 1] = next;
    }
}
Exemplo: [64, 25, 12, 22, 11] i=1: next=25, desloca 64 → [25, 64, 12, 22, 11] i=2: next=12, desloca 64, 25 → [12, 25, 64, 22, 11] i=3: next=22, desloca 64 → [12, 22, 25, 64, 11] i=4: next=11, desloca 64, 25, 22, 12 → [11, 12, 22, 25, 64]

Complexidade: Melhor caso O(n) | Pior caso O(n²) | Estável: sim | In-place: sim

Quando o vetor já está ordenado, o Insertion Sort apenas percorre os elementos sem fazer deslocamentos — O(n). No pior caso (vetor invertido), cada elemento precisa ser deslocado até o início — O(n²).

// 04

Bubble Sort — ordenação por bolha

O Bubble Sort percorre o vetor várias vezes, trocando elementos adjacentes que estão fora de ordem. A cada passagem, o maior elemento "flutua" até sua posição final (como uma bolha).

bubble sort em C
void bubbleSort(int vet[], int tam) {
    int i, j, temp;
    for (i = tam - 1; i > 0; i--) {
        for (j = 0; j < i; j++) {
            if (vet[j] > vet[j + 1]) {
                temp = vet[j];
                vet[j] = vet[j + 1];
                vet[j + 1] = temp;
            }
        }
    }
}
Exemplo: [64, 25, 12, 22, 11] Passagem 1: 25 12 22 11 [64] Passagem 2: 12 22 11 [25] 64 Passagem 3: 12 11 [22] 25 64 Passagem 4: 11 [12] 22 25 64

Complexidade: Melhor caso O(n) | Pior caso O(n²) | Estável: sim | In-place: sim

Assim como o Insertion Sort, o Bubble Sort pode ser otimizado para parar quando nenhuma troca ocorre em uma passagem — o que dá O(n) no melhor caso.

// 05

QuickSort — ordenação rápida

O QuickSort é um algoritmo recursivo de divisão e conquista. Escolhe um pivô e rearranja o vetor de modo que os elementos menores que o pivô fiquem à esquerda e os maiores à direita (particionamento). Depois, ordena recursivamente cada parte.

particionamento e quicksort em C
// Recebe vetor v[p..r] com p <= r. Rearranja
// os elementos do vetor e devolve j em p..r
// tal que v[p..j-1] <= v[j] < v[j+1..r].
int separa (int v[], int p, int r) {
    int c = v[r]; // pivô (último elemento)
    int t, j = p;
    for (int k = p; k < r; ++k)
        if (v[k] <= c) {
            t = v[j], v[j] = v[k], v[k] = t;
            ++j;
        }
    t = v[j], v[j] = v[r], v[r] = t;
    return j;
}

void quicksort (int v[], int p, int r) {
    if (p < r) {
        int j = separa (v, p, r);
        quicksort (v, p, j - 1);
        quicksort (v, j + 1, r);
    }
}

Complexidade: Melhor caso O(n log n) | Pior caso O(n²) | Estável: sim | In-place: sim | Recursivo: sim

O pior caso O(n²) ocorre quando o vetor já está ordenado e a escolha do pivô é sempre o extremo. A escolha do pivô impacta diretamente a eficiência.

Rastreamento do QuickSort

Rastreamento passo a passo do QuickSort no vetor [9, 8, 1, 4, 3] com pivô sendo o último elemento:

Chamada inicial: quicksort(v, 0, 4) | vetor: [9, 8, 1, 4, 3] separa(v, 0, 4): pivô c = 3, j = 0 k=0: 9 <= 3? F k=1: 8 <= 3? F k=2: 1 <= 3? V → troca v[0] c/ v[2]: [1, 8, 9, 4, 3], j=1 k=3: 4 <= 3? F Final: troca v[1] c/ v[4]: [1, 3, 9, 4, 8] Retorna j = 1 quicksort(v, 0, 0): não faz nada (p == r) quicksort(v, 2, 4): vetor [9, 4, 8] separa(v, 2, 4): pivô c = 8, j = 2 k=2: 9 <= 8? F k=3: 4 <= 8? V → troca v[2] c/ v[3]: [4, 9, 8], j=3 Final: troca v[3] c/ v[4]: [4, 8, 9] Retorna j = 3 quicksort(v, 2, 2): não faz nada quicksort(v, 4, 4): não faz nada Resultado: [1, 3, 4, 8, 9] ✓
O particionamento coloca o pivô em sua posição definitiva. A cada chamada de separa, pelo menos um elemento (o pivô) é colocado no lugar correto.

Merge Sort — ordenação por intercalação

O Merge Sort também é recursivo (divisão e conquista). Divide o vetor ao meio até ter subvetores de 1 elemento (trivialmente ordenados) e depois intercala as metades ordenadas, gerando um vetor ordenado maior. Usa um vetor temporário durante a intercalação.

intercala e mergesort em C
// A função recebe vetores crescentes v[p..q-1] e v[q..r-1]
// e rearranja v[p..r-1] em ordem crescente.
void intercala (int p, int q, int r, int v[]) {
    int *w = malloc((r - p) * sizeof(int));
    int i = p, j = q, k = 0;
    while (i < q && j < r) {
        if (v[i] <= v[j]) w[k++] = v[i++];
        else              w[k++] = v[j++];
    }
    while (i < q) w[k++] = v[i++];
    while (j < r) w[k++] = v[j++];
    for (i = p; i < r; ++i) v[i] = w[i - p];
    free(w);
}

void mergesort (int p, int r, int v[]) {
    if (p < r - 1) {
        int q = (p + r) / 2;
        mergesort (p, q, v);
        mergesort (q, r, v);
        intercala (p, q, r, v);
    }
}

Complexidade: Melhor caso O(n log n) | Pior caso O(n log n) | Estável: sim | In-place: não (usa vetor auxiliar) | Recursivo: sim

O Merge Sort é o único algoritmo aqui que tem desempenho garantido O(n log n) em todos os casos. A desvantagem é o uso de memória extra O(n) para o vetor temporário.

// 09

Exercícios de fixação

Quiz rápido

1. Qual a complexidade do Selection Sort no melhor caso?

✔ Correto! Selection Sort sempre percorre o vetor restante procurando o menor elemento. Melhor e pior caso são O(n²).
✘ O Selection Sort SEMPRE faz n + (n-1) + ... + 1 comparações — O(n²).

2. Qual algoritmo de ordenação NÃO é in-place?

✔ Correto! Merge Sort usa um vetor auxiliar de tamanho O(n) durante a intercalação, portanto não é in-place.
✘ Merge Sort precisa de memória extra O(n) para o vetor temporário da intercalação.

3. Em que situação o Insertion Sort é mais eficiente que o QuickSort?

✔ Exato! Insertion Sort tem melhor caso O(n) em vetor ordenado e constante pequena. É ideal para vetores pequenos ou quase ordenados.
✘ Insertion Sort é O(n) no melhor caso (vetor ordenado). Sua simplicidade e baixo overhead o tornam rápido para entradas pequenas ou quase ordenadas.

4. O que causa o pior caso O(n²) no QuickSort?

✔ Correto! Quando o vetor já está ordenado e o pivô é o último elemento, as partições ficam desbalanceadas, gerando O(n²).
✘ O pior caso ocorre quando o pivô é sempre o menor ou maior elemento, o que acontece em vetores já ordenados com pivô extremo.
