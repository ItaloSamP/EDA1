// 01

Busca — visão geral

analogia do dia a dia

Buscar um dado em um vetor é como procurar um livro em uma estante: se os livros estão bagunçados (desordenados), você precisa olhar um por um (busca sequencial). Se estão ordenados por título, você pode ir direto ao meio e decidir se o livro está antes ou depois (busca binária).

A busca é uma das operações mais frequentes em computação. A eficiência de uma busca depende diretamente de como os dados estão organizados na memória.

A aula aborda três cenários:

  • Busca sequencial em vetor desordenado — sem pré-requisitos
  • Busca sequencial em vetor ordenado — pode parar antes
  • Busca binária em vetor ordenado — salto direto ao meio

Por que ordenação importa? Um vetor ordenado permite estrategias de busca muito mais eficientes (O(log n) contra O(n)), economizando tempo — especialmente em grandes volumes de dados.

// 02

Busca sequencial em vetor desordenado

Não há qualquer restrição sobre o vetor. A busca percorre todos os elementos do início ao fim até encontrar o valor desejado (ou até chegar ao final sem sucesso).

busca sequencial em vetor desordenado — C
/* Busca por 'valor' em vetor 'v' de tamanho 'n'.
 * Retorna o índice se encontrar, -1 caso contrário. */
int buscaSequencialDesordenado(int v[], int n, int valor) {
    for (int i = 0; i < n; i++)
        if (v[i] == valor)
            return i;
    return -1;
}
Exemplo: v = [34, 12, 7, 98, 3, 21], busca por 7 i=0: v[0]=34 ≠ 7 i=1: v[1]=12 ≠ 7 i=2: v[2]=7 == 7 → retorna 2 Busca por 99: i=0: 34, i=1: 12, i=2: 7, i=3: 98, i=4: 3, i=5: 21 Fim do vetor → retorna -1

Complexidade: Melhor caso O(1) | Pior caso O(n) | Caso médio O(n)

Se o elemento está na primeira posição, uma única comparação resolve. Se não existe ou está no final, percorre o vetor inteiro. Não há ganho com ordenação aqui, pois não podemos assumir nada sobre a posição dos elementos.

// 03

Busca sequencial em vetor ordenado

Quando o vetor está ordenado, podemos interromper a busca precocemente: se o valor na posição atual já é maior que o procurado, certamente o valor não está no restante do vetor.

busca sequencial em vetor ordenado — C
/* Vetor v está ordenado crescentemente.
 * Retorna o índice ou -1 se não encontrado. */
int buscaSequencialOrdenado(int v[], int n, int valor) {
    for (int i = 0; i < n; i++) {
        if (v[i] == valor)  return i;
        if (v[i] > valor)   break;
    }
    return -1;
}
Exemplo: v = [3, 7, 12, 21, 34, 98], busca por 7 i=0: v[0]=3 < 7 → continua i=1: v[1]=7 == 7 → retorna 1 Busca por 15: i=0: v[0]=3 < 15 → continua i=1: v[1]=7 < 15 → continua i=2: v[2]=12 < 15 → continua i=3: v[3]=21 > 15 → break → retorna -1

Complexidade: Melhor caso O(1) | Pior caso O(n) | Caso médio O(n/2)

A ordenação permite encerrar a busca antes do final quando o elemento procurado não existe, mas no pior caso (elemento no final) ainda é O(n).

// 04

Busca binária

A busca binária (binary search) é um algoritmo de divisão e conquista que explora o fato de o vetor estar ordenado. A cada passo, compara o valor procurado com o elemento do meio e:

  • Se igual → encontrou (retorna o índice)
  • Se menor → busca na metade esquerda
  • Se maior → busca na metade direita
busca binária — C (iterativa e recursiva)
/* Versão iterativa */
int buscaBinariaIterativa(int v[], int n, int valor) {
    int esq = 0, dir = n - 1, meio;
    while (esq <= dir) {
        meio = (esq + dir) / 2;
        if (valor == v[meio])     return meio;
        else if (valor < v[meio]) dir  = meio - 1;
        else                     esq = meio + 1;
    }
    return -1;
}

/* Versão recursiva */
int buscaBinariaRecursiva(int v[], int esq, int dir, int valor) {
    if (esq > dir) return -1;
    int meio = (esq + dir) / 2;
    if (valor == v[meio])
        return meio;
    else if (valor < v[meio])
        return buscaBinariaRecursiva(v, esq, meio - 1, valor);
    else
        return buscaBinariaRecursiva(v, meio + 1, dir, valor);
}
Exemplo: v = [3, 7, 12, 21, 34, 98], busca por 12 esq=0, dir=5, meio=2: v[2]=12 == 12 → retorna 2 Busca por 34: esq=0, dir=5, meio=2: v[2]=12 < 34 → esq=3 esq=3, dir=5, meio=4: v[4]=34 == 34 → retorna 4 Busca por 8 (não existe): esq=0, dir=5, meio=2: v[2]=12 > 8 → dir=1 esq=0, dir=1, meio=0: v[0]=3 < 8 → esq=1 esq=1, dir=1, meio=1: v[1]=7 < 8 → esq=2 esq=2, dir=1: esq > dir → retorna -1

Complexidade: Melhor caso O(1) | Pior caso O(log n) | In-place: sim | Recursivo/iterativo: ambos

A cada iteração, o espaço de busca é reduzido à metade. Para um vetor de 1 milhão de elementos, a busca binária precisa de no máximo ~20 comparações contra até 1 milhão da busca sequencial.

A busca binária exige que o vetor esteja ordenado. Se for necessário ordenar primeiro, considere o custo da ordenação no custo total da operação.

// 06

Exercícios de fixação

Quiz rápido

1. Qual a complexidade da busca binária no pior caso?

✔ Correto! A busca binária reduz o espaço pela metade a cada passo — O(log n).
✘ Busca binária é O(log n). Cada iteração descarta metade do vetor.

2. Qual a principal diferença entre busca sequencial em vetor desordenado e ordenado?

✔ Sim! Em vetor ordenado, se v[i] > valor, o elemento não existe — podemos interromper a busca.
✘ A ordenação permite a parada antecipada: se v[i] > valor, o elemento procurado não está à direita.

3. Em um vetor de 1024 elementos, quantas comparações a busca binária faz no máximo?

✔ Exato! log₂(1024) = 10, e o pior caso executa 10 + 1 = 11 comparações (considerando a última comparação de igualdade).
✘ log₂(1024) = 10 → no máximo 11 comparações (incluindo a verificação final).

4. Qual pré-requisito a busca binária exige?

✔ Correto! A busca binária só funciona corretamente em vetores ordenados.
✘ Sem a ordenação, a premissa "se é menor está à esquerda" não se sustenta.
