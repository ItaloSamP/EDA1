## Estrutura

```
Provas/

└── P2/
    ├── ExemplosQuestões/       — questões de provas anteriores (24.1)
    │   ├── Q1(24.1).c
    │   ├── Q2(24.1).c
    │   ├── Q3(24.1).c
    │   ├── Q4(24.1).c
    │   └── Q5(24.1).c

        ├── ComplexidadeComputacional/

        │   ├── prova_busca.html

        ├── AlgoritmoDeOrdenação/
        │   ├── prova_ordenacao.html
        │   └── gabarito_verificacao.c
        └── EstruturasLineares/
            ├── prova_estruturas.html
            └── gabarito_verificacao.c
```

---

## Como usar

1. Abra o `.html` do simulado desejado no navegador para fazer a prova cronometrado.
2. Compile e execute o `gabarito_verificacao.c` para conferir as respostas de código.
3. Consulte o `Padrão_Provas.pdf` para entender o formato e critérios de correção.
