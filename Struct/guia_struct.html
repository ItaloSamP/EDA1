O que é uma struct?

analogia do dia a dia

Uma struct é como uma ficha de cadastro. A ficha de um aluno tem campos: nome, matrícula, IRA, data de nascimento. Cada campo guarda um tipo diferente de informação. A struct em C faz exatamente isso — agrupa variáveis de tipos diferentes sob um único nome, formando um tipo composto que você mesmo define.

Até aqui você trabalhou com tipos primitivos: int, float, char. Com struct, você cria seus próprios tipos adaptados ao problema que está resolvendo — um Aluno, um Produto, um Ponto no plano.

📌 struct é um tipo de dado composto: agrupa campos de tipos potencialmente diferentes em uma única variável.

📌 Cada campo é acessado pelo operador ponto (.) na variável direta ou pelo operador seta (->) no ponteiro.

📌 Uma struct não é uma função — ela tem apenas dados, sem comportamento.

✔ Representar entidades reais: Aluno, Produto, Ponto, Data, Retângulo

✔ Organizar dados relacionados em uma única variável coerente

✔ Construir estruturas de dados: listas, árvores, filas e pilhas

✔ Passar grupos de dados relacionados para funções de forma limpa

// 02

Declaração e acesso — struct.c e struct1.c

A definição de uma struct usa a palavra-chave struct seguida de um nome (tag) e de um bloco { } com os campos. Para criar uma variável desse tipo, escreve-se struct NomeTag variavel;.

struct.c — declaração, atribuição e leitura de campos
#include <stdio.h>
#include <string.h>

/* Definição do tipo — fica fora das funções */
struct Aluno {
    char  nome[50];
    int   matricula;
    float ira;
};

int main() {
    struct Aluno a1;              /* declara variável do tipo */

    strcpy(a1.nome, "Ana");       /* acessa campo com . (ponto) */
    a1.matricula = 221001;
    a1.ira       = 8.5f;

    printf("Nome:      %s\n",  a1.nome);
    printf("Matricula: %d\n",  a1.matricula);
    printf("IRA:       %.1f\n", a1.ira);
    return 0;
}
struct1.c — inicialização direta e cópia de struct
struct Ponto { float x; float y; };

int main() {
    /* inicialização por lista (na ordem dos campos) */
    struct Ponto p1 = {3.0f, 4.0f};

    /* cópia de struct — copia campo a campo (tipos primitivos) */
    struct Ponto p2 = p1;   /* p2 é cópia independente */
    p2.x = 0.0f;            /* não afeta p1 */

    printf("p1: (%.1f, %.1f)\n", p1.x, p1.y);  /* 3.0, 4.0 */
    printf("p2: (%.1f, %.1f)\n", p2.x, p2.y);  /* 0.0, 4.0 */
    return 0;
}

typedef — simplificando o nome do tipo

Escrever struct Aluno em todo lugar é verboso. O typedef cria um alias para o tipo, permitindo usar apenas Aluno no lugar de struct Aluno.

Sem typedef
struct Aluno {
    char  nome[50];
    float ira;
};

struct Aluno a1;
struct Aluno turma[30];
struct Aluno *p;
Com typedef (idiomático em C)
typedef struct {
    char  nome[50];
    float ira;
} Aluno;

Aluno a1;
Aluno turma[30];
Aluno *p;
Com typedef struct { ... } NomeDoTipo; o tipo passa a ser apenas NomeDoTipo. É a convenção mais usada em código C moderno e é o padrão adotado nos exercícios do curso.
// 04

Structs em funções — funcaoStruct.c e mediaNotas.c

Structs podem ser passadas para funções por valor (cópia) ou por referência (via ponteiro). A diferença é fundamental tanto para a correção quanto para a eficiência.

funcaoStruct.c — por valor vs. por referência
typedef struct { char nome[50]; float ira; } Aluno;

/* Por VALOR: recebe cópia — alterações NÃO afetam o original */
void exibir(Aluno a) {
    printf("%s — IRA: %.1f\n", a.nome, a.ira);
}

/* Por REFERÊNCIA: recebe endereço — alterações AFETAM o original */
void aplicarBonus(Aluno *a, float bonus) {
    a->ira += bonus;
    if (a->ira > 10.0f) a->ira = 10.0f;
}

int main() {
    Aluno a1 = {"Carlos", 7.5f};
    exibir(a1);                    /* Carlos — IRA: 7.5 */
    aplicarBonus(&a1, 1.0f);
    exibir(a1);                    /* Carlos — IRA: 8.5 */
    return 0;
}
mediaNotas.c — struct com vetor de notas
typedef struct {
    char  nome[50];
    float notas[4];
    float media;
} Aluno;

void calcularMedia(Aluno *a) {
    float soma = 0;
    for (int i = 0; i < 4; i++)
        soma += a->notas[i];
    a->media = soma / 4.0f;
}

int main() {
    Aluno a1 = {"Maria", {8.0, 7.5, 9.0, 6.5}, 0};
    calcularMedia(&a1);
    printf("%s: media = %.2f\n", a1.nome, a1.media); /* 7.75 */
    return 0;
}

⚡ Eficiência: Passe structs por ponteiro sempre que possível. Por valor copia todos os bytes da struct a cada chamada. Use const Aluno *a para leitura sem risco de modificação acidental.

Arrays de structs — arraysStruct.c, cadastro.c e cadastroPessoas.c

Vetores de structs representam coleções de entidades: uma turma de alunos, um estoque de produtos, uma lista de contatos.

arraysStruct.c — vetor de structs e busca do maior IRA
#include <stdio.h>
#include <string.h>
typedef struct { char nome[50]; int idade; float ira; } Aluno;

int main() {
    Aluno turma[3];

    strcpy(turma[0].nome, "Ana");    turma[0].idade = 20; turma[0].ira = 8.5f;
    strcpy(turma[1].nome, "Bruno");  turma[1].idade = 22; turma[1].ira = 7.0f;
    strcpy(turma[2].nome, "Carla");  turma[2].idade = 21; turma[2].ira = 9.2f;

    int melhor = 0;
    for (int i = 1; i < 3; i++)
        if (turma[i].ira > turma[melhor].ira) melhor = i;

    printf("Melhor IRA: %s (%.1f)\n", turma[melhor].nome, turma[melhor].ira);
    return 0;
}
cadastroPessoas.c — leitura interativa com scanf via ponteiro
typedef struct { char nome[50]; int idade; char cpf[15]; } Pessoa;

void lerPessoa(Pessoa *p) {
    printf("Nome: ");   scanf("%49s", p->nome);
    printf("Idade: ");  scanf("%d", &p->idade);
    printf("CPF: ");    scanf("%14s", p->cpf);
}

void exibir(const Pessoa *p) {
    printf("[%s | %d anos | %s]\n", p->nome, p->idade, p->cpf);
}

int main() {
    Pessoa pessoas[3];
    for (int i = 0; i < 3; i++) { printf("\n--- Pessoa %d ---\n",i+1); lerPessoa(&pessoas[i]); }
    printf("\n=== Cadastro ===\n");
    for (int i = 0; i < 3; i++) exibir(&pessoas[i]);
    return 0;
}
Array turma[3] na memória: turma[0] turma[1] turma[2] ┌──────────────┐ ┌──────────────┐ ┌──────────────┐ │ nome: "Ana" │ │ nome:"Bruno" │ │ nome:"Carla" │ │ idade: 20 │ │ idade: 22 │ │ idade: 21 │ │ ira: 8.5 │ │ ira: 7.0 │ │ ira: 9.2 │ └──────────────┘ └──────────────┘ └──────────────┘ turma[0].nome turma[1].ira turma[2].idade etc.

Structs aninhadas — structaninhada.c e areaRetangulo.c

Um campo de uma struct pode ser ele mesmo outra struct. Isso modela hierarquias de dados de forma natural.

structaninhada.c — Data dentro de Aluno
typedef struct { int dia; int mes; int ano; } Data;

typedef struct {
    char  nome[50];
    Data  nascimento;   /* campo do tipo Data — struct aninhada */
    float ira;
} Aluno;

int main() {
    Aluno a = {"Ana", {15, 3, 2003}, 8.5f};

    printf("%s\n", a.nome);
    printf("%02d/%02d/%d\n",
           a.nascimento.dia,   /* dois pontos encadeados */
           a.nascimento.mes,
           a.nascimento.ano);
    return 0;
}
areaRetangulo.c — Ponto dentro de Retangulo
typedef struct { float x, y; } Ponto;

typedef struct { Ponto topEsq; Ponto botDir; } Retangulo;

float area(Retangulo r) {
    return (r.botDir.x - r.topEsq.x) * (r.botDir.y - r.topEsq.y);
}

int main() {
    Retangulo rect = {{0, 0}, {5, 4}};
    printf("Area: %.1f\n", area(rect));  /* 20.0 */
    return 0;
}

Para acessar campos aninhados, encadeie os pontos: a.nascimento.dia. Leia da esquerda para a direita: "o campo nascimento de a, e dentro dele o campo dia".

Ponteiro para struct — operador -> — structPonteiro.c

Quando você tem um ponteiro para struct, o operador seta (->) é a forma compacta e idiomática de acessar campos.

Forma longa (desreferência + ponto)
Aluno *p = &a1;

/* parênteses obrigatórios!
   . tem precedência maior que *  */
(*p).ira  = 9.0f;
(*p).nome[0] = 'B';
Forma curta — seta (idiomático)
Aluno *p = &a1;

/* p->campo equivale a (*p).campo
   mais limpo, mais legível        */
p->ira  = 9.0f;
p->nome[0] = 'B';

📌 Regra prática: Você tem a struct direta? Use .    Você tem um ponteiro para a struct? Use ->

Aluno a1 = {"Ana", 221001, 8.5}; Aluno *p = &a1; /* p guarda o endereço de a1 */ p ─────────────────────► a1 (endereço 0x3000) ┌──────────────┐ │ nome: "Ana" │ ◄── p->nome ou (*p).nome │ matric:221001│ ◄── p->matricula │ ira: 8.5 │ ◄── p->ira └──────────────┘ p->ira = 9.5 → modifica a1.ira diretamente (sem cópia)!
structPonteiro.c — struct com campo ponteiro e uso de ->
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    char *nome;       /* campo ponteiro — string no heap */
    int   matricula;
} Aluno;

Aluno criaAluno(const char *nome, int mat) {
    Aluno a;
    a.nome = (char*) malloc(strlen(nome) + 1);
    strcpy(a.nome, nome);
    a.matricula = mat;
    return a;
}

void liberaAluno(Aluno *a) {
    free(a->nome);   /* libera o campo ponteiro */
    a->nome = NULL;
}

int main() {
    Aluno a1 = criaAluno("Italo Samuel", 221032);
    printf("%s — mat %d\n", a1.nome, a1.matricula);
    liberaAluno(&a1);
    return 0;
}
Ao copiar uma struct com campo ponteiro (a2 = a1), ambas ficam apontando para o mesmo endereço de memória (cópia rasa). Liberar uma torna a outra inválida (dangling pointer). Implemente sempre uma função de cópia que faz malloc + strcpy para o campo ponteiro.

Resumo — . vs -> e boas práticas

SituaçãoOperadorExemplo
Variável direta. (ponto)a1.nome, a1.ira
Ponteiro para struct-> (seta)p->nome, p->ira
Desreferência manual(*ptr).campo(*p).nome — evitar, prefira ->
Struct aninhada direta. encadeadoa.nascimento.dia
Ponteiro p/ struct aninhada-> e .p->nascimento.dia
Campo ponteiro (lista)Dependeno->prox, no->prox->valor

Fluxo de boas práticas

1. Definir a struct fora das funções (escopo global de tipo). 2. Usar typedef para evitar repetir "struct NomeTag". 3. Para structs grandes, passar SEMPRE por ponteiro. 4. Usar const Aluno *p quando a função só vai ler os dados. 5. Se a struct tem campo ponteiro: - Crie função criaAluno() → aloca o campo ponteiro (malloc + strcpy) - Crie função copiaAluno() → deep copy (aloca nova memória) - Crie função liberaAluno() → free do campo + atribui NULL 6. Inicializar com {0} para zerar todos os campos na declaração.

Referência rápida de erros comuns

ErroO que fazer
a1.nome = "texto"Strings char[] não aceitam atribuição direta — use strcpy(a1.nome, "texto")
p.campo (com ponteiro)Use seta: p->campo (ponto é só para variável direta)
a2 = a1 (campo ponteiro)Cópia rasa — implemente deep copy com malloc+strcpy
(*p).campo sem parênteses*p.campo é erro: ponto tem precedência maior que *. Use ->.
free(a) em struct com ptrLibere o campo ponteiro ANTES de liberar a struct inteira

Exercícios de fixação

Quiz rápido

1. Dada Aluno *p = &a1;, qual é a forma correta de acessar o campo ira?

✔ Correto! p é ponteiro → use p->ira. O ponto (p.ira) é só para variáveis diretas. A seta é um atalho para (*p).ira.
✘ Para ponteiro para struct use a seta: p->ira. O ponto (.) funciona apenas para variável direta. A seta equivale a (*p).ira.

2. O que acontece ao fazer Aluno a2 = a1; quando a1 tem campo char *nome?

✔ Exato! A cópia de struct é rasa (byte a byte), incluindo o valor do ponteiro. Ambas compartilham o mesmo endereço. Liberar uma deixa a outra com dangling pointer.
✘ A cópia copia apenas o endereço, não o conteúdo. É uma cópia rasa. Implemente deep copy com malloc + strcpy para copiar o conteúdo apontado independentemente.

3. Por que passar struct grande por ponteiro é mais eficiente do que por valor?

✔ Correto! Por valor, todos os bytes da struct são copiados na pilha a cada chamada. Para structs grandes, é custoso. Por ponteiro, apenas o endereço (4 ou 8 bytes) é passado.
✘ Por valor copia todos os campos na pilha — ineficiente para structs com muitos dados. Use ponteiro: const Aluno *p para leitura, Aluno *p para modificação.

4. Como acessar o campo dia da struct aninhada nascimento em uma variável direta a1?

✔ Correto! Encadeie pontos: a1.nascimento acessa o campo Data, e .dia acessa o campo dentro dele. A seta (->) só é usada quando a1 é um ponteiro.
✘ Para variável direta use ponto encadeado: a1.nascimento.dia. Leia da esquerda: campo nascimento de a1, depois campo dia. Seta é para ponteiros.

5. Qual expressão é equivalente a p->ira?

✔ Correto! p->ira é um atalho para (*p).ira. Os parênteses são obrigatórios pois o ponto (.) tem precedência maior que o asterisco (*).
✘ p->ira equivale a (*p).ira. Os parênteses são necessários: sem eles *p.ira seria *(p.ira), que tentaria acessar campo ira de p — mas p é ponteiro, não struct.

Desafios para programar

Desafio 1 — Sistema de Alunos
Crie struct Aluno com nome, matrícula e vetor de 3 notas. Leia N alunos, calcule a média de cada um com função que recebe ponteiro para struct. Imprima aprovados (média ≥ 5.0) e reprovados ao final.

Desafio 2 — Catálogo de Produtos
Crie struct Produto com nome, código, preço e quantidade. Implemente funções lerProduto, exibirProduto e valorTotal (preço × quantidade). Leia 5 produtos e exiba o valor total do estoque.

Desafio 3 — Agenda com struct aninhada
Crie structs Data e Contato (nome, telefone, Data aniversario). Implemente função que recebe vetor de contatos e exibe quem faz aniversário em determinado mês.

Desafio 4 — Nó de lista encadeada
Crie struct No com campo int valor e struct No *prox. Implemente inserirInicio, exibirLista e liberarLista. Insira 5 valores e exiba a lista do início ao fim.
