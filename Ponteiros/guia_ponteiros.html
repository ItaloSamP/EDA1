O que é um ponteiro?

analogia do dia a dia

Imagine que sua memória RAM é um grande conjunto habitacional numerado. Cada apartamento tem um número (endereço) e um morador (valor). Um ponteiro é como uma folha de papel onde você anota o número de um apartamento. Você não carrega o apartamento no bolso — você carrega o endereço que te diz onde ele está. Com o endereço em mãos, você pode ir lá e modificar tudo que está dentro.

Em C, cada variável ocupa um espaço na memória RAM e possui um endereço único. Um ponteiro é uma variável especial que, em vez de guardar um dado comum (inteiro, float, char...), guarda o endereço de memória de outra variável.

📌 Variável comum: guarda diretamente o valor — int x = 42; → x contém 42.

📌 Ponteiro: guarda o endereço de outra variável — int *p = &x; → p contém o endereço onde x mora.

Por que ponteiros são tão importantes em C?

✔ Permitem que funções modifiquem variáveis externas (passagem por referência)

✔ São a base da alocação dinâmica de memória

✔ Possibilitam estruturas de dados complexas (listas, árvores, grafos)

✔ Tornam o acesso a vetores e strings mais eficiente

// 02

Declaração, & e * — os três pilares

Trabalhar com ponteiros exige dominar apenas três conceitos fundamentais: como declarar um ponteiro, como obter o endereço de uma variável e como acessar o valor apontado.

int *p; — declaração: o * aqui diz "p é um ponteiro para int"

&x — operador de endereço: retorna o endereço de memória de x

*p — desreferência: acessa o valor no endereço guardado em p

declaração e uso básico — IncrementoDireto.c / IncrementeIndireto.c
int  x = 10;          /* variável comum: guarda o valor 10          */
int *p = &x;          /* ponteiro: p guarda o ENDEREÇO de x         */

printf("Valor de x:     %d\n", x);   /* imprime: 10            */
printf("Endereco de x:  %p\n", &x);  /* imprime: 0x7fff...     */
printf("Valor de p:     %p\n", p);   /* imprime: 0x7fff...     */
printf("Valor via *p:   %d\n", *p);  /* imprime: 10 (deref.)   */

/* Incremento direto: altera x diretamente */
x++;                  /* x agora é 11                              */

/* Incremento indireto: altera x ATRAVÉS do ponteiro */
(*p)++;               /* x agora é 12 — os parênteses são essenciais! */
Cuidado com a precedência! *p++ incrementa o ponteiro (move para o próximo endereço), não o valor. Use (*p)++ para incrementar o valor apontado.
Memória RAM: Endereço Conteúdo Variável ────────────────────────────────────────── 0x1000 | 12 | x (o inteiro, valor atual) 0x1008 | 0x1000 | p (guarda o endereço de x) p ────────────────────────────► x (12) "p aponta para x" *p → vai até 0x1000 e lê/escreve lá

O * tem dois significados distintos

Na declaração
int *p;
/* "p é um ponteiro para int"
   Diz o TIPO da variável       */
No uso (expressão)
*p = 100;
/* Desreferência: vai até o
   endereço e acessa/altera     */

Mapa da memória e endereços — InspecaoMemoria.c

Para entender ponteiros profundamente, é essencial visualizar como as variáveis ficam organizadas na memória. O arquivo InspecaoMemoria.c explora exatamente isso: inspecionar endereços e valores lado a lado.

inspeção de memória — exibindo endereços reais
#include <stdio.h>

int main() {
    int   a = 10;
    int   b = 20;
    float f = 3.14f;
    char  c = 'Z';

    printf("Variavel | Endereco       | Valor | Tamanho\n");
    printf("a        | %p | %d     | %zu bytes\n", (void*)&a, a, sizeof(a));
    printf("b        | %p | %d     | %zu bytes\n", (void*)&b, b, sizeof(b));
    printf("f        | %p | %.2f   | %zu bytes\n", (void*)&f, f, sizeof(f));
    printf("c        | %p | %c      | %zu bytes\n", (void*)&c, c, sizeof(c));

    int *pa = &a;
    printf("\npa aponta para: %p\n", (void*)pa);
    printf("*pa = %d (o valor de a)\n", *pa);
    return 0;
}

Variáveis locais ficam na Pilha (Stack), alocadas automaticamente. Seus endereços são determinados em tempo de execução e variam a cada execução. O que importa é entender a relação: o ponteiro contém o endereço, e via desreferência você acessa o que está naquele endereço.

// 04

Incremento direto vs. indireto

Uma das primeiras operações estudadas com ponteiros é a diferença entre alterar uma variável diretamente (pelo nome) e indiretamente (via ponteiro). Isso é o fundamento da passagem por referência.

IncrementoDireto.c
void incrementaDireto(int n) {
    n++;  /* altera só a CÓPIA */
}

int main() {
    int x = 5;
    incrementaDireto(x);
    printf("%d\n", x); /* ainda 5! */
}
IncrementeIndireto.c
void incrementaIndireto(int *p) {
    (*p)++;  /* altera o ORIGINAL */
}

int main() {
    int x = 5;
    incrementaIndireto(&x);
    printf("%d\n", x); /* agora é 6! */
}
C sempre passa argumentos por valor — a função recebe uma cópia. Para modificar a variável original, passe o endereço dela e use um ponteiro dentro da função.
// 05

Modificação de variáveis via ponteiro — ModificacaoPonteiro.c

Passar um ponteiro para uma função é a forma correta de retornar múltiplos valores ou modificar variáveis do escopo chamador. Funções com retorno void podem "retornar" vários resultados através de ponteiros.

ModificacaoPonteiro.c — função que altera múltiplas variáveis
#include <stdio.h>

/* Calcula o quadrado e o cubo, retornando via ponteiros */
void potencias(int n, int *quad, int *cubo) {
    *quad = n * n;
    *cubo = n * n * n;
}

int main() {
    int quadrado, cubo;
    potencias(4, &quadrado, &cubo);
    printf("Quadrado: %d\n", quadrado);  /* 16 */
    printf("Cubo:     %d\n", cubo);      /* 64 */
    return 0;
}

📌 scanf usa exatamente esse padrão! scanf("%d", &n) — o &n passa o endereço de n para que scanf possa escrever o valor lido diretamente na variável.

// 06

Swap manual — trocando valores com SwapManual.c

O swap (troca de valores entre duas variáveis) é um exercício clássico para solidificar o entendimento de passagem por referência. Sem ponteiros, a troca acontece apenas nas cópias locais.

SwapManual.c — a troca correta com ponteiros
#include <stdio.h>

void swap(int *a, int *b) {
    int temp = *a;   /* salva o valor de *a em temp         */
    *a = *b;          /* copia o valor de *b para onde a aponta */
    *b = temp;        /* copia temp para onde b aponta        */
}

int main() {
    int x = 10, y = 20;
    printf("Antes:  x=%d, y=%d\n", x, y);  /* x=10, y=20 */
    swap(&x, &y);
    printf("Depois: x=%d, y=%d\n", x, y);  /* x=20, y=10 */
    return 0;
}
swap(&x, &y): Antes: x[10] y[20] ↑ ↑ a b Passo 1: temp = *a = 10 Passo 2: *a = *b → x = 20 Passo 3: *b = temp → y = 10 Depois: x[20] y[10] ✓ troca realizada no original!

Ponteiros e vetores — aritmética de ponteiros

Em C, o nome de um vetor é, essencialmente, um ponteiro para seu primeiro elemento. Isso significa que ponteiros e vetores são intercambiáveis em muitos contextos — e habilita a poderosa aritmética de ponteiros.

InverteVetor.c / MaiorElemVetor.c / IntercalacaoVetor.c — operações com ponteiros em vetores
int vet[5] = {10, 20, 30, 40, 50};
int *p = vet;               /* p aponta para vet[0]               */

/* Acesso equivalente */
printf("%d\n", vet[2]);     /* 30 — notação de índice              */
printf("%d\n", *(p + 2));   /* 30 — aritmética de ponteiro         */
printf("%d\n", p[2]);       /* 30 — notação de índice via ponteiro */

/* Percorrendo com ponteiro */
int *fim = vet + 5;         /* ponteiro "um além do fim"           */
for (int *it = vet; it < fim; it++)
    printf("%d ", *it);       /* 10 20 30 40 50                      */

InverteVetor.c — inversão com dois ponteiros

void inverte(int *vet, int n) {
    int *inicio = vet;
    int *fim    = vet + n - 1;

    while (inicio < fim) {
        int temp = *inicio;
        *inicio = *fim;
        *fim    = temp;
        inicio++;
        fim--;
    }
}

int main() {
    int v[] = {1, 2, 3, 4, 5};
    inverte(v, 5);
    /* v agora é: 5 4 3 2 1 */
}

MaiorElemVetor.c — retornando ponteiro para o maior elemento

int* maiorElem(int *vet, int n) {
    int *maior = vet;               /* começa assumindo que o 1º é o maior */
    for (int i = 1; i < n; i++)
        if (vet[i] > *maior)
            maior = &vet[i];        /* atualiza o ponteiro para o maior    */
    return maior;
}

int main() {
    int v[] = {3, 7, 2, 9, 4};
    int *pm = maiorElem(v, 5);
    printf("Maior: %d (posicao %ld)\n", *pm, pm - v);  /* 9 (posicao 3) */
}

💡 Diferença de ponteiros: pm - v retorna o número de elementos entre os dois endereços — neste caso, o índice do maior elemento. Isso é aritmética de ponteiros em ação!

Ponteiros e strings — char*

Em C, strings são vetores de char terminados por '\0'. O tipo char* (ponteiro para char) é a forma padrão de trabalhar com strings usando ponteiros.

ContaCaracC.c — contando caracteres com ponteiro
#include <stdio.h>

int contaCarac(char *s, char c) {
    int count = 0;
    while (*s != '\0') {   /* percorre até o fim da string */
        if (*s == c)
            count++;
        s++;               /* avança o ponteiro para o próximo char */
    }
    return count;
}

int main() {
    char str[] = "estrutura de dados";
    printf("'a' aparece %d vez(es)\n", contaCarac(str, 'a'));  /* 3 */
    return 0;
}
ComparacaoString.c — comparando strings caractere a caractere
int comparaStrings(char *a, char *b) {
    while (*a != '\0' && *b != '\0') {
        if (*a != *b)
            return *a - *b;   /* negativo, 0, ou positivo */
        a++;
        b++;
    }
    return *a - *b;            /* 0 se iguais              */
}

int main() {
    char s1[] = "EDA";
    char s2[] = "EDA";
    printf("%d\n", comparaStrings(s1, s2));  /* 0 — iguais */
    return 0;
}
String "EDA\0" na memória: Endereço: 0x2000 0x2001 0x2002 0x2003 Valor: 'E' 'D' 'A' '\0' ↑ char *p aponta aqui *p = 'E' → p++ → *p = 'D' → p++ → *p = 'A' p++ → *p = '\0' → FIM do loop

Ponteiro para ponteiro — **

Um ponteiro guarda um endereço. Um ponteiro para ponteiro guarda o endereço de outro ponteiro. É declarado com dois asteriscos: int **pp.

int x = 42; int *p = &x; /* p guarda o endereço de x */ int **pp = &p; /* pp guarda o endereço de p */ Memória: ┌──────────┐ ┌──────────┐ ┌──────────┐ │ pp │───►│ p │───►│ x │ │ (0x3000) │ │ (0x2000) │ │ 42 │ └──────────┘ └──────────┘ └──────────┘ 0x4000 0x3000 0x2000 **pp → 42 (dois níveis de desreferência) *pp → p (o ponteiro intermediário)
int   x  = 42;
int  *p  = &x;
int **pp = &p;

printf("%d\n", x);    /* 42 */
printf("%d\n", *p);   /* 42 */
printf("%d\n", **pp); /* 42 */

**pp = 100;
printf("%d\n", x);    /* 100 — x foi alterado via **pp */

Ponteiros para ponteiros são usados em: matrizes dinâmicas (int **mat), funções que precisam alterar um ponteiro (ex: void aloca(int **p)), e strings em argv (char **argv).

Uso clássico: alterar um ponteiro dentro de uma função

void inicializa(int **p, int valor) {
    *p = (int*) malloc(sizeof(int));
    **p = valor;
}

int main() {
    int *ptr = NULL;
    inicializa(&ptr, 99);
    printf("%d\n", *ptr);  /* 99 */
    free(ptr);
    return 0;
}

Fluxo padrão de uso de ponteiros

1. Declarar: int *p; 2. Inicializar: p = &x; (ou p = malloc(...)) 3. Verificar NULL: if (p == NULL) { ... } 4. Usar (ler): printf("%d", *p); 5. Usar (escrever): *p = novo_valor; 6. Se dinâmico: free(p); p = NULL;

Exercícios de fixação

Quiz rápido

1. Dado int x = 5; int *p = &x; — qual é o resultado de (*p)++?

✔ Correto! Os parênteses forçam a desreferência primeiro: (*p) acessa x, e ++ incrementa o valor. x passa a ser 6.
✘ (*p)++ acessa o valor de x (via desreferência) e depois incrementa. Como p aponta para x, x passa a ser 6. Sem parênteses, *p++ avançaria o ponteiro.

2. Por que a função void swap(int a, int b) NÃO funciona para trocar variáveis?

✔ Exato! Em C, todo argumento é passado por valor (cópia). Para alterar as variáveis originais, é necessário passar ponteiros: void swap(int *a, int *b).
✘ O problema é a passagem por valor. A função recebe cópias de a e b. Alterações nas cópias não afetam as variáveis originais. Use ponteiros: swap(int *a, int *b).

3. Qual é a diferença entre *p++ e (*p)++?

✔ Correto! ++ tem precedência maior que *. Então *p++ é *(p++) — lê o valor atual e avança p. Já (*p)++ incrementa o valor apontado por p.
✘ A precedência decide: ++ tem prioridade maior que *. *p++ é interpretado como *(p++) — lê o valor e avança p. (*p)++ usa parênteses para forçar a desreferência primeiro.

4. Se int v[] = {10, 20, 30}; e int *p = v;, o que imprime printf("%d", *(p+2));?

✔ Correto! p aponta para v[0] = 10. p+2 aponta para v[2] = 30. *(p+2) equivale a v[2] = 30.
✘ p aponta para v[0]. p+2 é aritmética de ponteiro que avança 2 posições int. Isso aponta para v[2] = 30. Logo *(p+2) = 30.

5. Para que serve um ponteiro para ponteiro (int **pp)?

✔ Correto! int **pp guarda o endereço de um ponteiro. Usos clássicos: alterar um ponteiro dentro de uma função, e criar matrizes dinâmicas (vetores de vetores).
✘ int **pp é um ponteiro para ponteiro: guarda o endereço de outro ponteiro. É fundamental para matrizes dinâmicas e funções que precisam modificar um ponteiro do chamador.
